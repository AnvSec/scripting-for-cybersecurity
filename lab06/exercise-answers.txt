Exercise 5
1. Searching access.log for sqlmap returns 22 matching lines; grep exits 0.
2. With -z instead of -n, a nonempty keyword is skipped. An empty keyword
   runs grep with an empty pattern, matching every line (80 in access.log).
   Both outcomes were tested in a temporary modified copy.
3. A missing keyword prints a count of 0 from grep -c, but grep exits 1.
   grep uses its exit status to indicate whether it found a match, not
   whether it successfully printed a number. STATUS=$? saves that result
   immediately. The script prints it on the next line.
4. Implemented: a zero count prints "No matches found.". A genuine grep
   error, such as the invalid regex [, returns script exit code 4 and
   writes an error to stderr. A normal no-match search still completes
   the overall statistics script successfully.
